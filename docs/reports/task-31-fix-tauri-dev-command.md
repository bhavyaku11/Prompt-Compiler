## 1. Root Cause

The project had no root-level `package.json`, so `npm run tauri dev` failed immediately with:

    npm error Missing script: "tauri"

Two compounding issues:

1. No root `package.json` → no npm script named "tauri" → installed `@tauri-apps/cli@^2.12.0` as root devDependency and added `"tauri": "tauri"` script.
2. `tauri.conf.json` `beforeDevCommand` used `../frontend` which resolved incorrectly when running from project root → changed to `./frontend`.
